# Project Conventions & Memory

## Automated Question Generation Guidelines
Whenever asked to generate quiz questions (especially in bulk or background), strictly adhere to the following rules:

1. **Target Audience**: Laboratory Technician (AIIMS CRE level).
2. **Difficulty**: Moderate to Hard only. Do not generate basic or trivial questions. The questions should match the standard of competitive medical laboratory exams.
3. **Quantity**: Aim for up to 100-200 questions per chapter, but prioritize **QUALITY OVER QUANTITY**. If you cannot find enough valid, accurate, non-repetitive moderate-to-hard questions for a specific chapter, you are absolutely allowed to generate fewer questions. Just notify the user about the final count.
4. **Syllabus Baseline**: The full syllabus (Microbiology, Biochemistry, Pathology, Haematology, etc.) is saved in `syllabus.md` in the root directory. Use that file for reference when generating chapter-wise questions. You do not need the user to re-upload the PDF.

## User Preferences
- The user expects proactive communication regarding the difficulty and amount of questions generated. If an exact number cannot be reached, just inform them. No need to stress about strict counts.
- The user is aware that background processes can take multiple iterations/goes to achieve 200 questions. Just keep them informed about the progress.
